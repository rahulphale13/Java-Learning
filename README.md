# Java-Learning
A collection of my Java programs, concepts, and practice projects as I build my programming skills.
## Topics Covered

This repository documents my Java learning journey through small programs and examples. So far, I have covered:

- **Java Basics** — Hello World program and basic program structure
- **Variables** — Declaring and using different variables
- **Data Types** — `int`, `double`, `char`, `boolean`, and `String`
- **User Input** — Taking input using the `Scanner` class
- **Conditional Statements** — `if`, `else if`, and `else`
- **Loops** — `for`, `while`, and `do-while`
- **Arrays** — Creating, storing, and accessing array elements
- **Methods** — Creating reusable methods, parameters, and return values
- **Start of Student Grade Clalculator**
- - **Constructor** — Practiced creating a parameterized constructor and passing values while creating an object.
